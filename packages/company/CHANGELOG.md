# Changelog

## 0.2.0

### Added

- `copyright({ link? })` and `copyrightHtml({ link? })`: the copyright notice `© RYUSENKEI`, without a year. The name links to `https://ryusenkei.co.jp/` unless `link` is `false`. `copyright()` returns `{ text, prefix, name, href? }` for building it in Astro or React.
- `copyright` (`{ text, href }`) in `company.json`.
