# コメントの手本

コメントは非自明な理由・制約のみ。処理の内容はコードの名前で表現

- 形の手本: `comments.ts`
- コミットメッセージの手本: `commit.txt`
- この文書・手本のファイルは prose-lint の規則を通る（試験で検査）

## 形の使い分け

| 用途 | 形 |
| --- | --- |
| ファイルの冒頭・複数の項目 | 1行目に要約、続く行に `- 項目: 値` の箇条書き |
| 1つの説明の補足 | 1行目に要約、続く行は3文字の字下げ（`//   `） |
| 型・定数のフィールド | 行末のコメントの開始位置を統一 |
| `export` する関数・型・定数 | JSDoc（`/** */`）。エディタの補完に表示 |
| 理由と結果 | `→` で接続 |

## 文の規則

- 1行は100字まで。超える場合は行を分割
- 1文は1行。長い文は分割・箇条書き（幅の調整を目的に折り返さない）
- 箇条書きの中は「。」で区切らず、「・」「→」で接続
- 「の」の連続は2つまで。3つ以上は複合語・語順で解消
- 常体・体言止め。推量の表現を避けて断定
- 語彙は漢語・エンジニア語彙（作成・削除・取得・返却）
- コード上の値・環境変数はバッククォートで囲む

## 指摘を修正するとき

- 指摘の末尾の「修正の例」を参照
- 語を置換するだけで不自然になる場合は、文を再構成
- ドメインの用語が語彙の規則に該当する場合は、設定の `allow` に追加
